# ADR-008 — No-root baseline

Status: Accepted

Date: 2026-09-22

## Context
Root access on the device would unlock more actions but varies by device/ROM,
is a deployment risk, and is mostly unnecessary: perception and the safe
action set work under `uid shell`.

## Decision
- **No-root baseline**: everything runs over `adb shell` under `uid shell`;
  the allowlist of read commands and safe actions requires no root.
- Root/grant-dependent paths are gated **EXPERIMENTAL** (config
  `actions.experimental`), opt-in, and never required.
- Any action must pass the safety gate (PRD CR-05) regardless of level
  (SAFE default-on, CONTROL gated via config).

## Consequences
- **Positive:** works on stock devices without rooting; smaller attack /
  risk surface; matches the device baseline (vivo V2157, Android 14).
- **Negative:** some deep inspection (e.g., certain `/data` reads) stays off
  the table in v1.
- **Neutral:** failure to read is handled as `UNKNOWN` (tolerant parsers,
  PRD §0.9), never as a crash.
